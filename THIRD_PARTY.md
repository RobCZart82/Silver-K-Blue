# Source provenance

Silver-K was extracted from [temaniak/ungeermoolator](https://github.com/temaniak/ungeermoolator), based on commit `f9a8e80d74c52d3a9771b069c60e8cb23b424232` plus the local Silver-K integration and K-Station/KS engine updates. This repository contains only the dependency subset used by Silver-K; unrelated synths, releases, ROMs and private test data were omitted.

The shared framework (including patchDB, UI, MIDI, resampling and bridge support) originates in [DSP56300/Gearmulator](https://github.com/dsp56300/gearmulator), with the changes from ungeermoolator. Gearmulator source is GPLv3; the license is preserved in [LICENSE.md](LICENSE.md). Existing per-file notices remain intact. The bridge subset is needed by the shared plugin framework and does not add another synth product.

Dependencies fetched at build time:

| Project | Repository | Revision |
| --- | --- | --- |
| JUCE 7 | dsp56300/JUCE | `2a8699d723fe9279e1148275485ddb0e18957f56` |
| DSP56300 | dsp56300/dsp56300 | `44353be2f0156cac970c6ab4f467ea1998b40605` |
| AsmJit | dsp56300/asmjit | `3577608cab0bc509f856ebf6e41b2f9d9f71acc4` |

Their original license files are downloaded with the source. JUCE is used under its GPLv3 option. AsmJit's source contains its own permissive license. DSP56300's original notices apply. The build-local JUCE patch replaces an unavailable macOS window snapshot API with NSView bitmap caching; it does not change synthesizer DSP.

The build-local MSVC patch adds the explicit third template argument to one `writeMem` call. This selects the overload Clang/GCC already select and resolves MSVC ambiguity; it does not change the operation or memory value.

Bundled source dependencies retain their notices:

- `source/3rdparty/libresample`: LGPL/BSD license files and README.
- `source/3rdparty/ptypes`: Hovik Melikyan's C++ Portable Types Library, per-file copyright notices.
- `source/framework/baseLib/sse2neon.h`: its embedded permissive license.
- `source/cpu/h8s`: H8S core as carried by ungeermoolator.

The two knob PNGs and skin JSON are source UI resources, not screenshots or release binaries. The single user-flash asset is generated by [`tools/create_init_flash.cpp`](tools/create_init_flash.cpp); no Novation ROM or factory sound data is distributed here.
