# Silver-K 0.2.4 — рабочая сборка macOS arm64, 16 октября 2026

Основа: 1724c1b, последний этап с полной сохранённой продуктовой проверкой
до последующего семантического переноса контроллера. Перенос заморожен;
checkpoint 909aa2b сохранён отдельно и в эту сборку не включён.

Два ранее проверенных режима KS — event DSP transport и control jobs —
включены по умолчанию. Переменные окружения больше не нужны для обычного
использования. Для диагностики прежние пути можно явно выбрать через
SILVER_KS_DSP_TRANSPORT=legacy и SILVER_KS_CONTROL_JOBS=0 до запуска хоста.
Это изменение выбора существующих путей, не новый алгоритм DSP/контроллера.
KS работает на C++ пути совместимости; регистровая/стековая модель остаётся.
K-Station, DSP firmware/JIT, clocks, buffers и приоритеты не менялись.

Пакет содержит Standalone, VST3 и AU, лицензии, соответствующие исходники,
контрольные суммы и синтетические KS Data/zero Wave. Оригинальные firmware,
factory presets и sampled Wave ROM не включены. Для работы укажите собственную
поддерживаемую K-Station OS 2.1.01 или KS OS 2.1.02 в Setup.

Установка: закройте хост; скопируйте приложение в Applications, VST3 в
~/Library/Audio/Plug-Ins/VST3, AU в ~/Library/Audio/Plug-Ins/Components.
Копируйте bundle целиком. Подробности: INSTALL.md. Сборка arm64, ad-hoc signed,
не notarized. Текущий пакет остаётся beta: слово «рабочая» не означает
проверку всех пресетов, хостов или физического инструмента.

Результаты текущих проверок и нового сравнения с OsTIrus записаны
в заключительной записи doc/OPTIMIZATION_LOG.md включённых исходников.
Отдельная таблица: doc/STABLE_PERFORMANCE_20261016_RU.md.
AU/VST3 проверены со звуком. Standalone открывает окно; если старое
состояние сообщает о пропавшей OS/Wave, заново выберите действующие файлы
через Load firmware, Wave ROM и KS factory data. Физическое аудиоустройство
Standalone в этом раунде не проверено.
Mac-проверки не являются Windows-проверками; прежние CPU-цифры нельзя
приписывать новому бинарнику без его собственного замера.
