# Silver-K 0.1.0

Единый Windows x64 Standalone / VST3 и macOS arm64 Standalone / VST3 / AU для оригинальных прошивок K-Station OS 2.1.01 и KS OS 2.1.02. Проект выделен из репозитория ungeermoolator и использует компоненты Gearmulator.

Внутри работают прежние оригинальные H8/DSP движки. Прошивка проверяется по содержимому и SHA-256, а не имени файла. Новая интеграция использует общий Gearmulator patchDB: сканирование папок, кэш, теги, избранное и изменения метаданных. Для K-Station используется существующий Gearmulator/libresample преобразователь частоты; для KS сохраняется существующий четырехканальный поток. ROM не включается в приложение или состояние проекта.

## Начало работы

1. На странице Setup выбрать ROM folder. Вложенные папки сканируются; поддерживаются decoded BIN, OS/SYX и ZIP с обновлением прошивки. Выбрать прошивку в верхнем меню.
2. Для KS в поле KS factory data указать наш `assets/ks-init-flash.bin` (524288 байт), содержащий только начальные звуки Silver-K. При желании официальный All Data MID можно подключить локально; в репозиторий он не входит. Отдельно можно указать Wave ROM (129024 байта). Если банк не указан, используется нулевой банк в памяти. Зависящие от ROM осцилляторы заглушаются оригинальными MIDI-командами; с настоящим банком адаптация выключена.
3. На Patches добавить папку, SYX, MID или ZIP. Файлы сканируются в фоне, включая вложенные папки. Двойной щелчок или Load загружает выбранный патч в выбранный тембр. Теги и избранное сохраняются отдельно от исходных файлов.

Библиотека находится в `~/Library/Application Support/The Usual Suspects/Silver-K/patches`. Для изолированных проверок используется переменная `SILVER_K_DATA`; это отдельная база, не заводские ROM.

## Интерфейс

Размер 1280 × 752 соответствует существующей панели Silver-K для K-Station. Сохранены OSC/Mixer/Filter/LFO/Env и нижние секции эффектов. Верхние страницы Main, Extra, Perf, Patches, Setup.

Четыре короткие вкладки 1–4 выбирают тембр. На K-Station доступны только настройки первого тембра; остальные вкладки затемнены. На KS включить Performance на Perf для работы четырех тембров. На этой странице находятся активность, MIDI-канал, диапазон клавиш, транспозиция, уровень, настройка выхода Main 1+2 / Aux 3+4 / Mono 1–4. Переключение вкладки само по себе не останавливает звучащие ноты других тембров.

В режиме Auto K-Station использует исходную темную нижнюю панель, KS — серую нижнюю панель с темными надписями. Setup позволяет выбрать Silver-K, KS Grey, Classic или загрузить собственный JSON на основе приложенного скина. Шаблон фиксированного размера 1280 × 752.

У VST3/AU две стереошины; Aux может быть отключена хостом. Standalone поддерживает 2 или 4 физических выходных канала. На K-Station выходы 3–4 молчат. Маршрутизация KS сохраняет его оригинальные MIDI-параметры и четырехтембральный движок.

## Совместимость патчей

Браузер показывает исходную модель по SysEx, Program/Performance, источник, теги и статус совместимости. Оригинальные данные остаются в базе. При загрузке преобразуется копия.

KS → K-Station:

- Все дополнительные осцилляторные волны (включая шумовые варианты) заменяются синусом.
- Любой фильтр становится LP 12 dB/oct — в том числе исходный LP 24.
- Дополнительные формы LFO и арпеджиатора заменяются значениями K-Station по умолчанию.
- Параметры, существующие только на KS (модуляция уровней, расширенные LFO, маршрутизация частей и другие расширения), не переносятся. Отчет сообщает о потерянных настройках, отличающихся от значений по умолчанию.
- Из Performance на K-Station переносится первый тембр. Четыре тембра на K-Station не воспроизводятся.

K-Station → KS сохраняет общий блок, извлекает упакованные волны и адаптирует кодирование дополнительных полей; настройки KS получают исходные значения. На KS Performance заменяется звук выбранной части с сохранением ее MIDI-канала/выхода/диапазона.

Native KS Performance загружается целиком и включает Performance. Native патчи сохраняют исходный звуковой payload. Заголовок нормализуется для загрузки в текущий звук, без записи во Flash синтезатора. При потерях показывается предупреждение и список замен.

В этой версии воспроизводятся и взаимно преобразуются K-Station/KS. A-Station SYX распознается и хранится с указанием модели, но преобразование пока не включено без подтвержденной карты. X-Station пока не имеет проверенного импорта. Они не выдаются за совместимые программы.

## Состояние и ограничения

Проект сохраняет выбранную модель, пути и хэши ROM, текущий нативный звук/Performance, пользовательские данные, тембр, скин и параметры. Теги/папки находятся в отдельной постоянной базе. Переключение прошивки — холодная перезагрузка движка; звук в этот момент прерывается. Старые самостоятельные K-Station/KS продукты и их plugin ID сохранены; Silver-K имеет собственный ID Tskv.

Все параметры двух моделей имеют постоянные host ID: KS — прежние имена и part2_/part3_/part4_, K-Station — k_. В интерфейсе доступны параметры выбранной модели; хост видит полный стабильный набор, чтобы автоматизация не меняла смысл после выбора ROM.

Для K-Station сохранен отдельный отключаемый mono вход Vocoder / external и общий входной преобразователь Gearmulator. У KS внешний аудиовход пока не подключен. Физическая точность относительно железа не установлена этой интеграцией. Существующие ограничения нулевого банка и общих MIDI-каналов KS сохраняются.

Сборки, локальные ROM, тестовые WAV и состояния проверки расположены вне отслеживаемых исходников. Win64 собирается в CI из тех же исходников; локальные звуковые проверки выполнены на современном macOS arm64; совместимость с macOS 12 нельзя утверждать по deployment target, поскольку зависимости собираются из исходников на текущем SDK.

## Проверки выпуска

`silver_check` проверяет преобразование дополнительных волн/LP 12/арпеджиатора, точность native payload, импорт папки, определение модели, сохранение тегов/избранного, общую базу экземпляров и наличие основных контролов скина. Прогон с локальными ROM дополнительно проверяет звук, live cutoff на удерживаемой ноте, тишину Aux на K-Station, восстановление обеих моделей, повторную prepareToPlay после K-Station state и полное KS Performance. В проверенных callback не было C++-выделений через operator new; это не отдельный перехват всех C malloc.

Преобразование KST100 сравнивалось с оригинальным KS UART-импортом: совпали все 151 синтезаторных байта при каждом из 16 исходных keysync значений. Это проверяет конкретный патч и варианты этого поля, а не звуковую идентичность двух физических инструментов.

Hosted VST3/AU: 48 kHz, 256 samples, 4 секунды realtime. KS — четыре выхода, peaks 0.0359975 / 0.0359963 / 0.0474905 / 0.0475713, underrun 0. K-Station — stereo peak 0.105694, underrun 0. Максимальный callback на этой машине: VST3 KS 0.113 ms, AU KS 0.065 ms; VST3 K-Station 0.192 ms, AU K-Station 0.159 ms. Проверки не включают задержку физического MIDI/драйвера.
