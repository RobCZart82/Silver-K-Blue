# Silver-K 0.2 Alpha — установка и первый запуск

Silver-K объединяет эмуляцию K-Station и четырёхчастных KS. Это ранняя альфа: патч-менеджер, быстродействие, задержка и оптимизация ещё дорабатываются.

## 1. Что находится в архиве

| Файл или папка | Назначение |
| --- | --- |
| `Standalone/Silver-K.app` или `Standalone/Silver-K.exe` | Самостоятельное приложение |
| `Plugins/VST3/Silver-K.vst3` | Плагин VST3 |
| `Plugins/AU/Silver-K.component` | Плагин AU, только Mac |
| `KS-Data/ks-wave-zero.bin` | Нулевая замена Wave ROM: 129024 байта без сэмплов |
| `KS-Data/ks-init-flash.bin` | Наши тестовые KS Data: 524288 байт, простые программы и Performance, стартовые настройки |
| `KS-Data/*.manifest.json` | Размеры, происхождение и SHA-256 тестовых файлов |
| `INSTALL_RU.md` | Эта инструкция |
| `RELEASE_NOTES_RU.md` | Описание версии и её ограничений |
| `release-manifest.json`, `SHA256SUMS.txt` | Состав релиза и контрольные суммы |
| `LICENSE.md`, `THIRD_PARTY.md`, `Licenses/`, `SOURCES.txt` | Лицензии и ссылки на соответствующие исходники |

**Оригинальная прошивка OS, заводские банки программ и реальные сэмпловые Wave ROM в архив не входят.** Их следует подключать из собственных локальных файлов. Наш нулевой Wave ROM и KS Init Flash не содержат кода Novation, заводских пресетов или записанных волн.

## 2. Установка на Mac

Этот архив предназначен для **Apple Silicon (arm64)**. В DAW используйте её нативный запуск для Apple Silicon. Плагин из этого архива не является Intel/x86_64 или Universal-сборкой.

1. Полностью распакуйте ZIP и закройте DAW перед заменой старых плагинов.
2. Для самостоятельного запуска перенесите `Standalone/Silver-K.app` в `/Applications` либо в свою папку приложений.
3. Для VST3 перенесите **всю папку** `Plugins/VST3/Silver-K.vst3` в:
   ```text
   ~/Library/Audio/Plug-Ins/VST3/
   ```
4. Для AU перенесите **всю папку** `Plugins/AU/Silver-K.component` в:
   ```text
   ~/Library/Audio/Plug-Ins/Components/
   ```
5. В Finder нужную папку удобно открыть через **Переход → Переход к папке…** (`Command+Shift+G`). Вставьте путь с `~`. Если папки формата нет, создайте её.
6. При обновлении замените прежнюю папку плагина целиком. Сохраните старую версию отдельно, если хотите иметь возможность вернуться к ней. Не извлекайте исполняемый файл из `Contents/MacOS`.
7. Запустите DAW и выполните пересканирование плагинов. В Logic откройте Plugin Manager и при необходимости повторите проверку AU. Silver-K — инструмент, а не аудиоэффект; ищите его в списке синтезаторов.

Mac-сборки имеют ad hoc подпись, **без Developer ID и нотариализации Apple**. Если macOS блокирует приложение при первом запуске, проверьте источник архива и используйте штатное разрешение **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть** после попытки запуска. Не отключайте Gatekeeper для всей системы. Для плагина также может понадобиться штатное подтверждение разрешения и повторное сканирование в DAW. [Инструкция Apple](https://support.apple.com/102445).

Дополнительная проверка установленного AU в Терминале:

```sh
auval -v aumu Tskv TusP
```

## 3. Установка на Windows

Архив предназначен для **Windows x64** и 64-битной DAW.

1. Полностью распакуйте ZIP. Закройте DAW перед обновлением.
2. Standalone можно запускать из постоянной папки, например `Документы\Silver-K\Standalone\Silver-K.exe`. Не запускайте программу внутри ZIP.
3. Перенесите **всю папку** `Plugins\VST3\Silver-K.vst3` в стандартную папку VST3:
   ```text
   C:\Program Files\Common Files\VST3\
   ```
   Windows может запросить права администратора для копирования. Не переносите отдельно DLL из внутренней структуры `.vst3`.
4. При обновлении замените прежнюю папку `Silver-K.vst3` целиком, затем пересканируйте VST3 в DAW.
5. Если Windows сообщает об отсутствии `VCRUNTIME140`, `MSVCP140` или другой библиотеки Visual C++, установите официальный **Microsoft Visual C++ v14 Redistributable x64**. [Страница Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
6. В Standalone откройте настройки аудиоустройства, выберите доступный выход и MIDI-вход. Эта сборка использует стандартные Windows-бэкенды JUCE; локально подключаемый ASIO SDK в архив не включён.

AU существует только на macOS. Плагины VST2 в этот релиз не входят.

## 4. Где хранить ROM, KS Data и factory presets

Выберите постоянную пользовательскую папку. Например:

```text
Документы / Documents
└── Silver-K
    ├── ROMs
    │   ├── ваша прошивка K-Station
    │   └── ваша прошивка KS
    ├── KS-Data
    │   ├── ks-init-flash.bin
    │   ├── ks-wave-zero.bin
    │   └── ваши оригинальные KS Data / Wave ROM, если есть
    └── Presets
        ├── K-Station
        └── KS
```

Скопируйте `KS-Data` из архива в эту постоянную папку. Прошивки положите в `ROMs`, банки звуков — в `Presets`. Не храните их во временной папке загрузок, которую затем удалите. Не нужно помещать ROM в системные папки VST3/AU или внутрь `.app`, `.component`, `.vst3`: Silver-K выбирает файлы по пути в Setup.

Плагин запоминает пути и проверяет содержимое поддержанной прошивки. Сам код OS и Wave ROM в состояние проекта DAW не встраивается. Если файлы перенесены, укажите их заново; при переносе проекта на другой компьютер понадобятся такие же локальные файлы.

## 5. Прошивка OS — отдельный обязательный файл

Поддержаны **K-Station OS 2.1.01** и **KS OS 2.1.02**. Имя архива может не совпадать с внутренней версией — проверка идёт по содержимому и контрольной сумме.

1. Поместите свою прошивку в `ROMs`.
2. В Silver-K откройте **Setup → ROM folder** и выберите эту папку. Вложенные папки сканируются.
3. Поддерживаются соответствующие обновления OS/SYX, decoded BIN и ZIP с поддержанной прошивкой. Прошивку также можно выбрать кнопкой **Load firmware**. ZIP заводских звуков не является ZIP прошивки.
4. Для KS сначала подключите KS Data, как описано ниже, затем выберите KS в верхнем меню прошивок. Дождитесь завершения `Loading firmware...`.

Нулевой `ks-wave-zero.bin` и `ks-init-flash.bin` нельзя выбирать через **Load firmware**: в них нет OS. Подключение только тестовых файлов без настоящей поддержанной прошивки не запускает синтезатор.

Официальные загрузки KS OS и factory sounds: [Novation KS Rack](https://downloads.novationmusic.com/novation/synthesisers-legacy/ks-rack). Скачанные оригинальные файлы остаются у пользователя и не входят в этот релиз.

## 6. Первый запуск KS с нашими тестовыми данными

Для базовой проверки не нужны заводские программы: `KS Init Flash` содержит наши собственные простые звуки. Он нужен для заполнения пользовательских программ, Performance и стартовых настроек; это **KS Data, а не Wave ROM**.

1. Скопируйте оба файла `KS-Data` из архива в постоянную папку.
2. В **Setup → KS factory data** выберите `ks-init-flash.bin` размером **524288 байт**.
3. В **Setup → Wave ROM** выберите `ks-wave-zero.bin` размером **129024 байта**.
4. Через **ROM folder** или **Load firmware** подключите свою KS OS 2.1.02 и выберите её в верхнем меню.
5. Дождитесь окончания загрузки. Проверьте выбранный выход, аудиоустройство и MIDI-канал. В одиночном режиме используется глобальный/editor MIDI-канал, выбранный в Setup.
6. Начальный `Silver Init` использует обычную генерируемую пилу. Сыграйте ноту. В Standalone выберите свой MIDI-вход; в DAW создайте инструментальный трек, включите его мониторинг и отправьте MIDI в Silver-K.
7. Для четырёх частей откройте **Perf**, включите **Performance (4 parts)** и проверяйте выбранную часть вкладками 1–4. Проверьте **Part active**, MIDI-канал, диапазон клавиш и Output. Для обычного стереоподключения выберите Main 1+2.

Нулевой Wave ROM — заменитель отсутствующих сэмплов. На нём доступны генерируемые волны, но программы, которым нужны сэмпловые волны/ударные, могут молчать или звучать неполно. Нулевой банк не восстанавливает оригинальные тембры KS. Плагин распознаёт нулевой банк и приглушает зависимые от него источники.

KS **Program boost (dB)** — усиление программы 0–30 dB. Значение 0 dB соответствует обычному уровню без добавочного усиления. Для общего уровня выбранной части используйте **Part volume** 0–127 на Perf; большое усиление программы может дать перегруз. Входящие MIDI-контроллеры по общему каналу действуют на все части слоя, а правки редактора и автоматизация tuning/уровня адресуются выбранной части.

## 7. Оригинальные KS Data / factory Data

Если у вас есть полный заводской MIDI-набор KS с SysEx или совместимый полный user Flash `.bin`, его можно использовать **вместо** `ks-init-flash.bin`:

1. Распакуйте официальный архив Data/factory sounds в постоянную пользовательскую папку.
2. В **Setup → KS factory data** выберите полный `.mid` / `.midi` с KS Program/Performance SysEx либо совместимый user Flash `.bin` размером **524288 байт**.
3. Если KS уже загружен, выбор новых Data запускает его повторную загрузку. Это прерывает текущий звук, поэтому меняйте Data между воспроизведениями.
4. Убедитесь, что KS прошивка загружена. Полученные программы и Performance добавляются в источник `KS Factory` в Patches. Название источника также используется при тестовых Data: `Silver Init` там не является оригинальным заводским звуком.

Обычный MIDI-файл с нотами и музыкальной партией не является KS Data. Обновление OS тоже не является банком пользовательских программ. Произвольный короткий `.bin`, отдельный Wave ROM или отдельный program SysEx не подходят в качестве полного user Flash. В MIDI для KS Data должны быть поддержанные программные/Performance SysEx; при ошибке Silver-K выводит сообщение в Setup.

Замена factory Data не заменяет Wave ROM. Если заводская программа требует сэмплов, нулевой Wave ROM всё равно даст тишину или неполный тембр. Для таких звуков нужен ваш совместимый реальный Wave ROM, отдельно выбранный в **Setup → Wave ROM**. Поддержанный файл этого банка имеет размер **129024 байта**. Файлы иных размеров/форматов автоматически не конвертируются.

## 8. Factory presets и пользовательские банки в Patches

Полные KS Data для инициализации и библиотека отдельных патчей — разные способы загрузки.

1. Поместите банки и отдельные патчи в `Presets`. Поддерживаются распознанные `.syx`, `.mid`, `.midi`; браузер также умеет читать ZIP с такими файлами. Для понятной структуры можно сначала распаковать ZIP.
2. В Silver-K откройте **Patches → Add folder** и выберите папку банка. Вложенные папки сканируются. Через **Add file** можно добавить один банк или файл.
3. Дождитесь результатов сканирования. При необходимости нажмите **Rescan** и сбросьте фильтры модели/источника/тегов.
4. Выберите строку патча и нажмите **Load** либо дважды щёлкните по строке.
5. В KS Performance перед загрузкой выберите нужную часть вкладкой 1–4. Program загружается в выбранную часть; Performance содержит всю четырёхчастную конфигурацию. В некоторых путях загрузки пресета Performance перечитывается целиком и звук может прерваться.
6. Для текущего звука используйте **Save current**, для выбранной строки библиотеки — **Export .syx**. Изменённые теги/избранное сохраняйте через **Save tags**.

K-Station запускается со своей OS и не требует KS Init Flash или KS Wave ROM. Её factory presets добавляются через Patches таким же способом. Преобразование K-Station ↔ KS поддерживается с заменой несовместимых функций; смотрите отчёт при загрузке. A-Station можно распознать и хранить в библиотеке, но его конвертация и проверенный X-Station импорт в этой версии не реализованы.

Патч-менеджер пока не завершён. Проверяйте сохранённые звуки повторной загрузкой и держите исходные банки отдельно. Настройки в проекте DAW сохраняйте после применения изменений к движку, а не сразу в момент перемещения регулятора.

## 9. Если нет звука или плагин работает медленно

- **Нет прошивки / ошибка версии:** выберите поддержанную OS через Setup. Тестовые Data и нулевой банк не являются OS.
- **KS требует Data:** подключите KS Init Flash или совместимые полные factory Data.
- **Silver Init звучит, factory patch молчит:** проверьте требование сэмплового Wave ROM. Нулевой банк не содержит этих волн.
- **В Performance молчит часть:** проверьте Part active, MIDI-канал, Lowest/Highest note и Output. Aux 3+4 должен быть включён в DAW; при двухканальном выходе направьте часть на Main 1+2.
- **Звук перегружен:** уменьшите Program boost и уровни осцилляторов/Part volume. 0 dB boost — исходный уровень, а не выключение голоса.
- **Пропуски или высокая CPU:** проверьте аудиоустройство и увеличьте размер аудиобуфера для теста. Это может увеличить общую задержку. Работа с несколькими частями и маленькими буферами ещё требует оптимизации.
- **Заметная задержка:** показатель Host latency в Setup относится к плагину. Задержки аудиодрайвера, MIDI-устройства и цепочки DAW добавляются отдельно. Уменьшение буфера снижает задержку, но повышает требования к CPU.
- **Плагин не появляется:** проверьте правильную папку и архитектуру DAW, перезапустите/пересканируйте плагины; на Windows проверьте Visual C++ runtime, на Mac — штатное разрешение запуска.

Это рабочая отправная точка для дальнейшего развития, а не финальная оптимизированная версия. Аудиовход KS пока не подключён; равенство звука с физическими инструментами не установлено.
