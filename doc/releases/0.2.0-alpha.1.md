# Silver-K 0.2 Alpha

Первая публичная альфа-линия Silver-K для дальнейшего развития единого K-Station / KS плагина. Номер внутри приложения — **0.2.0**, тег релиза — **v0.2.0-alpha.1**.

## Архивы

- **Windows x64:** Standalone и VST3.
- **macOS Apple Silicon (arm64):** Standalone, VST3 и AU. Intel/Universal-сборки в этом релизе нет.

В каждом архиве находятся подробная русская инструкция `INSTALL_RU.md`, лицензии, ссылки на соответствующие исходники, контрольные суммы и два наших тестовых файла для KS:

- **`ks-wave-zero.bin` — нулевая замена Wave ROM**, 129024 байта. Нужна как заменитель отсутствующего банка сэмплов. Генерируемые волны работают; звуки на сэмпловых волнах/ударные могут молчать или звучать неполно.
- **`ks-init-flash.bin` — тестовые KS Data**, 524288 байт. Содержит наши простые `Silver Init` программы, `Silver Multi` Performance и стартовые настройки. Даёт возможность проверить базовую работоспособность KS без загрузки оригинальных factory Data. Его можно заменить своими совместимыми полными factory Data MIDI/user Flash.

Эти файлы не содержат оригинальную OS, DSP firmware, заводские патчи или сэмплы Novation. Для запуска пользователь отдельно подключает **K-Station OS 2.1.01** либо **KS OS 2.1.02**. Тестовые KS Data выбираются через **Setup → KS factory data**, нулевой Wave ROM — через **Setup → Wave ROM**, настоящая прошивка — через **ROM folder / Load firmware**. [Официальные загрузки KS](https://downloads.novationmusic.com/novation/synthesisers-legacy/ks-rack).

[Подробная установка: плагины, OS, Wave ROM, KS Data, factory presets](https://github.com/temaniak/Silver-K/blob/v0.2.0-alpha.1/doc/INSTALL_RU.md). Та же инструкция вложена в каждый архив.

## Что исправлено

- Контраст надписей и переключателей страницы Perf; громкость части доступна прямо на этой странице.
- Индивидуальная адресация правок редактора и автоматизации частей KS, включая tuning и громкость, при общем MIDI-канале. Игра слоями сохраняется; эти правки не перечитывают Performance и не обрывают удерживаемые ноты.
- KS Program boost исправлен с ошибочного 0–127 на штатный **0–30 dB**. Значение 0 dB — обычный уровень. Недопустимые старые boost-значения восстанавливаются в 0 dB. Host ID сохранён, но нормализованная автоматизация boost теперь соответствует новому диапазону.
- Проверки маршрутизации слоёв, состояния, чтения UI и взаимодействия внешнего NRPN с редактором.

## Что ещё не завершено

**Патч-менеджер недоработан.** Импорт, организация банков, теги, совместимость моделей и сценарии сохранения ещё совершенствуются. Проверяйте результат повторной загрузкой и сохраняйте исходные банки отдельно. Часть путей смены пресетов перечитывает Performance и прерывает звук. A-Station conversion и проверенный X-Station импорт пока не реализованы.

**Быстродействие и оптимизация недоработаны.** CPU-нагрузка, фоновые загрузки/прогрев, многотембральные режимы и работа при маленьких буферах требуют дальнейших улучшений. Комфортная работа на всех системах/хостах не гарантирована этой альфой.

**Задержка ещё требует доработки.** Буферизация движка, аудиодрайвер и цепочка DAW влияют на общую задержку. Значение Host latency в Setup не включает физический MIDI и задержку драйвера; окончательная оптимизация будет продолжена.

У KS пока не подключён внешний аудиовход. Нулевой Wave ROM не даёт аутентичных сэмпловых тембров. Физическая точность звука относительно аппаратных K-Station/KS не установлена. Большое допустимое Program boost всё ещё может давать перегруз.

Mac-пакеты имеют ad hoc подпись, без Developer ID/нотариализации Apple; штатное разрешение запуска описано в инструкции. Windows-сборке может потребоваться официальный Visual C++ v14 Redistributable x64. Это **pre-release / Alpha**, основа для дальнейшего совершенствования плагина.
