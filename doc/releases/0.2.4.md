# Silver-K 0.2.4 Beta

This beta updates the previous public **0.2.0-alpha.1** release. The application/plugin version and release tag are **0.2.4** and **v0.2.4**. This remains a GitHub pre-release.

## Downloads and installation

- **Windows x64:** Standalone and VST3.
- **macOS Apple Silicon (arm64):** Standalone, VST3 and AU. Intel and Universal builds are not included.

Each package includes installation instructions, licenses, corresponding source, SHA-256 checksums, our synthetic KS Init Flash and a zero-filled Wave ROM substitute. Original firmware, factory presets and sampled Wave ROMs are not included. Supply supported K-Station OS 2.1.01 or KS OS 2.1.02 separately.

[Detailed installation guide](https://github.com/temaniak/Silver-K/blob/v0.2.4/doc/INSTALL.md). Close the DAW before replacing plugin bundles, then restart and rescan. Silver-K is an instrument. Avoid keeping multiple AU copies in the user and system plugin folders.

## Changes since 0.2 Alpha

- **Patch selection and sorting:** presets load on a single selection or re-click; the separate Load button is removed. All six table columns sort in either direction and retain the selected row. Conversion reports appear in the browser instead of interrupting selection with modal dialogs.
- **Bank menu:** populated folders, multi-program files and factory/storage banks appear in the selector. Individual preset files remain in the table. Rescan preserves the selected collection; Rescan All still refreshes individually imported files. Re-adding an existing source avoids duplicate rows.
- **A-Station and X-Station:** supported program dumps and banks are recognized and loaded through the compatible K and KS sound formats. Older A-Station filter-drive handling follows the firmware importer. Cross-engine import retains the existing target-model limitations.
- **Conversion corrections:** fixed program-level bias, KS Glide Curve mapping and packed fields when importing K-format sounds into KS. Unsupported attenuation in KS is reported rather than wrapping into a large boost.
- **V-Station:** supported legacy NvS0 FXB banks and FXP presets import directly, through recursive folders or ZIP. The source model has its own Model/filter entry, independent of editable tags. Internal preset names and slot identity are retained. Invalid or unrelated VST containers are rejected. This uses the existing K/KS engines; it does not add a V-Station DSP engine.
- **Preset names:** individual K/A SysEx names use their filenames, including ZIP members. Unnamed programs receive numbered model names rather than identical zeros. Import-cache migration preserves user tags and favourites.
- **Audio interruptions:** host state reads and KS diagnostics no longer pause firmware workers. Unchanged host preparation preserves the running engine. Worker scheduling, host audio-workgroup participation and post-warm-up realtime priority were improved.
- **Buffer choice:** Setup offers Low latency, Balanced, Safe and Maximum. The choice persists in project state and changes without rebooting the firmware. Low latency adapts to actual callback sizes instead of an AU host's larger preparation maximum. Plugin latency is shown in milliseconds; the physical interface buffer remains a DAW setting.
- **Host clock and arpeggiator:** host tempo, transport and position drive timed MIDI Clock. Tempo changes, start/stop and position jumps are handled. The KS firmware's interval-measurement timer now runs. Realtime MIDI bytes take priority over queued parameter edits, reducing clock delays during Pulse changes.
- **Permanent data folder:** Setup selects one main folder, defaulting to `Documents/Silver-K`, with `ROMs` and `Patches`. Missing synthetic Init Flash/zero Wave files are generated without overwriting existing assets. The ROM catalog and folder are remembered; startup restores the catalog without rescanning or decoding every archive. Rescan ROMs updates it explicitly. Relative asset paths and legacy projects are supported.
- **V-Station level in K:** selecting a V-Station preset reserves 6 dB using the firmware program-level control. Loud polyphonic presets, including both LD Bells Of Heaven variants, stay below the output ceiling in the checked captures. Filter, overdrive, EQ and effect settings and original source/library files are retained. Native K/A and KS playback levels are unchanged. No output limiter or additional latency is introduced.

## Updating existing projects

Previously saved projects keep their saved program level. **Select the V-Station preset again** to apply the new K playback level. Restoring a newly saved adjusted state does not subtract the gain a second time. A one-time refresh of old patch sources updates import metadata without rescanning the ROM catalog.

## Validation and limits

Local macOS arm64 checks passed for conversion, host clock, patch workflow and KS part MIDI. The 400-slot EDM Underworld bank and all 250 TranceStorms FXP files imported. Source selection survived Rescan without individual FXP entries returning to the bank menu. Captures covered both engines and 13 preset-name groups, with finite audible output and zero counted C++ allocations in checked audio callbacks.

For LD Bells Of Heaven at 48 kHz, volume/velocity 127 and a held four-note chord, the K peak fell from approximately 0.991 to 0.689; the second variant reached 0.690 after adjustment. The clean KS probe reached 0.243 and did not exceed full scale. Authored filter overdrive was retained. This addresses K playback headroom, not intentional preset distortion or exact equivalence with the original V-Station.

Live buffer/state-read checks passed in the tested configurations. In an AU-like 1024-frame preparation / 128-frame callback test, settled Low latency reporting was 7.92 ms for K and 5.33 ms for KS. Physical MIDI/audio-driver delay is additional. Small reserves can still underrun during cold JIT, CPU overload or sudden block-size changes; Balanced or higher provides more reserve.

KS external audio input is not connected. Zero Wave ROM does not recreate sampled waves or drums. Sound accuracy against original instruments/software is not established. High program boost and downstream mixer/effect gain can overload the signal. macOS bundles are ad hoc signed, without Developer ID signing or Apple notarization; use the installation guide's normal macOS approval procedure.

Windows release builds and ROM-free tests run in GitHub Actions. Original private firmware and user sound banks are excluded from all release packages.
