# Silver-K 0.2.3 Alpha 1

V-Station individual presets now import from FXP files (`CcnK` / `FPCh`, plugin ID `NvS0`, one program, 149-byte chunk), directly, through recursive folder scans or inside ZIP. This complements the existing 400-slot FXB importer. The 128-byte sound and 21-byte chunk name are retained; stale outer labels such as “User 300” are ignored. Unrelated VST presets and malformed containers are rejected before producing any patch.

V-Station is now a distinct source synth type in the Model column and model filter. The source identity is stored in model metadata independently of editable user tags. Existing V-tagged banks are recognized too. K playback sends the shared sound format directly, preserving the sound bytes. KS continues to use its K-compatible firmware importer and its 16-character name field. This source-model change does not add a separate V-Station DSP engine. Hardware SysEx export carries the shared K sound data; V identity and names are library metadata.

K-Station and A-Station presets now retain individual SysEx filenames, including member filenames inside ZIP archives. Unnamed banks receive model/number names, including sequential numbers when every message addresses edit buffer zero. Cached numeric placeholder names also have a readable numbered fallback. Existing imported file/folder sources refresh once after this importer upgrade, preserving sound hashes, user tags and favourites. ROM catalogs are unaffected by this patch-source refresh. Source files remain unchanged.

Local macOS arm64 validation:

- Four scoped CTest checks passed: patch workflow, conversion, host clock and KS part MIDI. Workflow checks include strict FXP rejection, FXB slot preservation, the V-Station model/filter, K/A naming and source-cache migration with favourites preserved.
- The supplied TranceStorms folder contains 250 FXP files across two subfolders, representing 127 unique named sounds. Every file imported with its original chunk name and all 128 sound bytes intact.
- Both K and KS displayed all 250 recursive folder rows as V-Station, filtered them correctly and loaded the selected name on click. Presets from 13 distinct name prefixes were played through the original firmware. Output was finite and audible, with zero counted C++ allocations in the checked callbacks. This checks import/playback, not identical sound to the original V-Station plugin.
- The existing EDM Underworld 400-slot FXB archive passed the name/payload/model checks again.

The 0.2.2 audio scheduling, host clock, buffer selection and remembered ROM catalog remain in this build. This change adds no work to audio callbacks. Release bundles contain authored synthetic data and a source snapshot; private presets and original firmware are not included. macOS bundles are locally ad-hoc signed and are not notarized. Windows compilation remains in the build workflow; local validation was on macOS arm64.
