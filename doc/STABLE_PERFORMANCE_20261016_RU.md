# Silver-K / OsTIrus: повторное сравнение, 16 октября 2026

Проверена именно новая рабочая сборка macOS arm64 на основе 1724c1b,
с двумя ранее проверенными оптимизациями по умолчанию. Полный перенос
контроллера заморожен; поздний checkpoint 909aa2b в пакет не включён.

Apple M1 Pro, macOS 27.2; AU, 48 кГц / 256 сэмплов; 16 нот всего.
Single: один part / 16 нот; Multi: четыре part / четыре ноты каждый.
Три чередующиеся пары по восемь секунд на сценарий. 100% = одно ядро.
Весь CPU процесса user+system, включая все его потоки. Подготовка и прогрев
вне измерения. У обоих инструментов проверены звучание частей, значения
параметров и активность эффектов в FX-сценариях.

| Scenario | Silver-K median (range) | OsTIrus median (range) | Silver-K relative CPU |
| --- | ---: | ---: | ---: |
| Single, dry | 46.703% (44.012–46.715) | 73.485% (62.996–76.821) | -36.45% |
| Single, delay/reverb/chorus | 45.271% (44.957–46.065) | 72.702% (63.349–76.491) | -37.73% |
| Four parts, dry | 45.469% (44.912–45.621) | 69.141% (65.629–82.173) | -34.24% |
| Four parts, delay/reverb/chorus | 44.760% (44.474–44.765) | 84.010% (61.029–88.811) | -46.72% |

Во всех 24 окнах звук конечный и слышимый, нет просроченных callback.
У Silver-K во всех 12 окнах ноль потерянных кадров; повторные рендеры
каждого сценария совпадают по звуку и хвостам. Внутренние потери OsTIrus
хост не видит. Хеши бинарников не изменились за время измерения.

Результат относится к этим тестам: Silver-K потреблял меньше CPU во всех
четырёх сценариях. Это не оценка скорости одинакового синтеза: прошивки,
алгоритмы/уровни эффектов и родные частоты различаются. OsTIrus 2.2.16/TI2.
Фоновая активность mds/RustDesk присутствовала; частоты/температуры/размещение
ядер не измерены. Диапазоны OsTIrus широкие. Старые и новые серии не объединены;
изменение относительно вчерашних абсолютных цифр отдельно не объясняется.
Нет Windows-замера и нет универсального обещания преимущества для всех патчей.

Тест: stable-mac-delivery-20261016. Приватные firmware, preset state, PCM,
полные трассы и персональные отчёты в пакет не входят. Исходник проверочного
AU-хоста включён в исходники; частные тестовые состояния не распространяются.
